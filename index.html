CSV & XLSX Viewer

Browser-based viewer for CSV and Excel files with inline row filtering. No upload, no server — everything runs locally.

CSV Viewer

Load CSV files and browse them as a full table. Supports custom delimiters, sortable columns, and inline cell highlighting.

XLSX Viewer

Load Excel files (.xlsx, .xls, .xlsm, .ods). Parses all sheets individually with the same filtering and table view.
